# Finova – Financial Analytics Dashboard

Finova is a modern, futuristic financial analytics dashboard designed to help users visualize and understand their financial activities through an intuitive interface.

## Features

- Firebase Authentication (Login & Registration)
- Secure email and password authentication
- Interactive financial dashboard
- Animated financial metric cards
- Income and expense analytics
- Interactive charts using Chart.js
- Weekly, monthly and yearly filters
- Transaction search and filtering
- CSV transaction export
- Dark and light mode
- Responsive user interface
- Futuristic dark navy and electric blue theme

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Chart.js
- Google Fonts

## Project Purpose

The goal of Finova is to create a visually appealing and user-friendly financial analytics platform that simplifies financial data visualization and improves the user experience.
